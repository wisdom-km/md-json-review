# ADR 0001 档位改为单机工具

## 背景

开工时把这个仓库定成曳光弹，只留一条能跑的路径当骨架。见 `DECISIONS.md` 2026-11-17 第一行，以及 `docs/evidence/g0.md`。

后来已经落地的不是骨架：页块对齐、题目和答案拆分、JSON Schema 校验、手动保存前的备份、导出前的备份。这些都会留下来用。

`project-essentials` 只有三档：原型、曳光弹、长期。没有「单机工具」这个名字。

## 选项

1. 继续叫曳光弹。文档仍说这是骨架。
2. 升成长期产品。门禁改用长期那一组，包括别人能访问时的 M-10。
3. 改称单机工具。承认拆分、校验和备份已经是这个工具的功能。仍只给一个人在本机用，不连数据库，不升成长期。

## 决定

选 3。

- 档位名称是单机工具。它不是曳光弹，也不是长期产品。
- [D] 仍是：另存稿在用户的书目录里。[P] 仍否：只监听 127.0.0.1。
- 不连接 k12-qbank，不连接 PostgreSQL。
- 门禁编号暂时仍按曳光弹：M-01 到 M-09，加 M-12。[D] 时 M-11。M-10 不适用。
- 需要人工决定：若要把门禁改成长期那一组，或给「单机工具」单独一张 MUST 表，由人选定。本决定不改那张表。
- `docs/evidence/g0.md` 保持开工时的记录，不改写成现在的档位。

## 后果

README 第一行、AGENTS 和 `DECISIONS.md` 的「现在」列改用这个名称。旧决定行的原文保留。

## 状态

采纳。2026-11-17。取代 `DECISIONS.md` 里「档位是曳光弹」那一行。
